# ReviewMyCode

> AI-powered GitHub PR reviewer that analyzes pull requests using Gemini AI and provides smart code reviews.

## 🚀 Live Demo

🔗 https://reviewmycode-three.vercel.app

---

# 📌 Features

- 🤖 AI-powered PR reviews using Gemini
- 🔍 Analyze GitHub pull requests automatically
- 🧠 Smart suggestions for code quality & improvements
- 📄 Review comments generated in real-time
- 🎨 Modern and responsive UI
- 🔐 Secure API integration

---

# 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### APIs & Tools
- Gemini API
- GitHub API
- Docker
- Vercel / Render
